# Annaelle — студия лазерной эпиляции

В репозитории находятся исходная версия основного сайта и обновлённая тестовая версия для согласования.

## Актуальная тестовая версия

https://efilym89.github.io/mainsiteannaelle/

GitHub Pages публикует `docs/` из ветки `agent/github-preview`. Исходники текущего тестового сайта находятся в `preview-site/`: все страницы, стили, скрипты, переводы, фотографии и шрифты. Основная ветка `main` и действующая версия Sites этим обновлением не затрагиваются.

Тестовый сайт включает десять страниц, RU/UZ/EN, прайс и абонементы, результаты с ползунком сравнения, страницу SILK CARD и форму выбора услуги. У фотографий «до/после» убраны ссылки на полноэкранный просмотр. Другие галереи сохранены.

Форма работает в тестовом режиме и не отправляет заявки. Telegram открывает черновик для @annaellelaser; пользователь отправляет его сам. Исходник карты Silk содержит противоречие о допустимых отменах, поэтому пока правила получения подарка предлагается уточнить у мастера.

### Сборка и проверка превью

Нужен Node.js 22.13 или новее. Установка зависимостей для статического превью не требуется.

```bash
npm run preview:github
node scripts/serve-static-preview.mjs
```

Локальное превью: http://127.0.0.1:4190/mainsiteannaelle/

Сборка проверяет синтаксис скриптов, режим теста и ссылки на ресурсы. Затем создаёт все страницы в `docs/`, добавляет префикс GitHub Pages и перенаправления для ранее опубликованных `/uz/...` и `/en/...`. Внутренние отчёты QA, переписка и пользовательские документы в публикацию не входят. В CI проверяется, что `docs/` воспроизводится из исходников.

Редактируйте `preview-site/`, после изменений запускайте `npm run preview:github` и сохраняйте изменения исходников вместе с `docs/` в тестовую ветку.

## Исходная версия Sites

Сохранена существующая структура Next.js / React / Vinext / Cloudflare Workers:

- `app/`, `components/`, `data/`, `lib/` — исходное приложение;
- `public/` — его исходные фотографии, изображения и шрифты;
- `worker/`, `db/`, `drizzle/` — Worker и схема D1;
- `.openai/hosting.json` — идентификатор исходного проекта Sites.

Для этой версии используются прежние команды `npm ci`, `npm run dev`, `npm run lint`, `npm test`. Не публикуйте её в Sites в рамках проверки GitHub Pages.
